# StrobeIT-Pro Firmware Updater

A browser-based firmware updater for StrobeIT-Pro & StrobeIT modules. Firmware files are selected locally and processed in the browser.

## Use the updater

Open the hosted updater in Chrome or Edge:

https://teravolt-labs.github.io/StrobeFlasher/

Connect a compatible StrobeIT programmer to the module matching the pins, select its serial port, choose an HEX or raw BIN firmware file, and start the update. Keep the module powered until verification finishes.

## Browser requirements

- Chrome or Edge with Web Serial support
- HTTPS or localhost
- A compatible StrobeIT programmer
